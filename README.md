# 🏅 Olympic Games Host Country Analysis

## 📌 Project Overview
This project analyzes the performance of **host countries** in the Olympic Games from **Athens 1896 to Beijing 2022**. By leveraging data mining and visualization techniques, we explore whether hosting the Olympics leads to **higher medal counts** and examine various trends in athlete and event data.

## 📊 Key Features
- 📂 **Dataset**: Retrieved from Kaggle, containing **medal counts, host country info, and athlete performance**.
- 🛠 **Data Processing**: Cleaned and normalized **150,000+ rows** of Olympic data, addressing inconsistencies.
- 📈 **Trend Analysis**: Investigated **medal counts, event participation, and host country effects**.
- 📊 **Visualizations**: Built insightful charts to showcase **medal trends, performance comparisons, and country-wise stats**.
- 🤖 **Hypothesis Testing**: Evaluated whether **host countries win more medals** than usual.

## 🗂️ Data Pipeline
1. **Data Cleaning** – Addressed missing values, inconsistencies, and standardized country/event names.
2. **Exploratory Analysis** – Investigated medal distribution across **hosts vs. non-hosts**.
3. **Visualization** – Used **Matplotlib & Seaborn** to display **medal trends and performance**.
4. **Statistical Analysis** – Identified key factors affecting **host country success**.

## 📌 Results & Insights
- Hosts tend to **win more medals** than in non-hosting years.
- Certain countries show **significant boosts**, while others remain stable.
- The impact varies based on **event type, athlete participation, and investment in sports**.

## 🛠 Tech Stack
- **Python** (Data Processing & Analysis)
- **Pandas & NumPy** (Data Cleaning & Transformation)
- **Matplotlib & Seaborn** (Visualization)
- **Jupyter Notebook** (Exploratory Analysis)
- **Kaggle Dataset** (Source Data)
